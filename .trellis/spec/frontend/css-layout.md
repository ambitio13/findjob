# CSS and Layout

## Application Shape

This is an operational productivity app, not a marketing site. Prefer dense,
quiet layouts that help users compare jobs and manage application state.

## Layout Rules

- Use an app shell with navigation, content area, and persistent feedback for
  running agent tasks.
- Keep tables readable at desktop widths.
- Provide mobile fallbacks for dense tables: stacked cards, filtered lists, or
  detail-first routes.
- Keep primary actions close to the relevant record.
- Do not place important approval controls where they can be confused with
  ordinary navigation.

## Visual Hierarchy

- Use status tags for application state and risk level.
- Use progressive disclosure for long JD text, analysis detail, and generated
  resume content.
- Keep empty states action-oriented: upload resume, configure preferences, start
  job search, or inspect agent run.
